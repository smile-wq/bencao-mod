# 本草 · Bencao

中医药主题的 Minecraft 生存玩法原型，版本 0.1.0。暂定 Minecraft **1.21.1 / NeoForge 21.1.249**，Java 21；客户端和服务端均需安装。

第一条玩法流程：**寻找种子 → 种植药材 → 烘干 → 研磨 → 配制 → 煎煮 → 饮用**。

## 当前内容

- 薄荷、艾草、人参：各有种子、8 个生长阶段、鲜药材、干药材、药粉。
- 药杵与药臼：使用 64 次后损坏，合成研磨时自动保留工具并扣耐久。
- 三种药饮：薄荷饮提供速度 I（90 秒），艾草饮提供抗性提升 I（45 秒），参蜜饮提供生命恢复 I（10 秒）。这些是游戏效果设定。
- 本草手札、中文及英文语言资源、独立创造模式物品栏、配方解锁。

## 从生存模式开始

1. 打掉**矮草或蕨**，每株有 10% 概率获得一颗药材种子。药种中薄荷占 50%、艾草 30%、人参 20%；使用剪刀或创造模式不触发。
2. 种在有光照的耕地上，附近放水。可以用骨粉催熟。成熟后打掉，获得 1–2 份鲜药材和 1–3 颗种子；未成熟时只返还 1 颗种子。
3. 鲜药材放入熔炉 **10 秒**或营火 **30 秒**，得到干药材。
4. 干药材与药杵合成，得到对应药粉。
5. 药粉 + 水桶 + 碗，合成一碗待煎药饮，返还空桶。**参蜜饮需要两份人参粉，并额外加入蜜脾。**
6. 待煎药饮放入熔炉 **20 秒**或营火 **30 秒**。喝下成品获得增益，返还碗；满饥饿值也可以喝。

药杵与药臼的工作台配方：

```text
空   木棍  空
圆石  碗   圆石
空   圆石  空
```

**书 + 小麦种子**可以合成本草手札，在游戏里查看完整流程。创造模式中搜索“本草”，或使用 `/give @s bencao:herbal_manual`。

## 构建与安装

这个原型使用本机已安装的 NeoForge 依赖离线编译，无额外运行时模组依赖。需要 PATH 中有 JDK 21 的 `javac` 与 `jar`。

```powershell
cd E:\Minecraft\mod_studio\bencao-mod
.\build.ps1
```

默认读取 `E:\Minecraft\cyhj0\.minecraft` 的 `HBUCM_Client` 和 `1.21.1` 版本清单及 NeoForge 21.1.249 库；其他同版本安装可以指定路径和实例名：

```powershell
.\build.ps1 -GameDirectory 'D:\Minecraft\.minecraft' -InstanceName 'MyInstance'
```

输出：`build/libs/bencao-0.1.0.jar`。将它放入对应 1.21.1 NeoForge 实例的 `mods` 文件夹；联机时服务端和客户端使用相同版本。构建脚本只生成项目内文件。

资源文件已随源码提供。修改配方或译文生成脚本后，先执行 `python tools/generate_resources.py`，再构建。

## 原型范围

目前使用原版纹理作为占位素材；植物外观分别借用胡萝卜、马铃薯和甜菜的阶段模型。独立药锅、晾药架、药柜，以及体质、辨证、疾病、村民医馆、野生药材分布尚未实现，后续可按玩法方向扩展。

初版用原版熔炉和营火完成烘干、煎煮，让采集到饮用的流程可以先行验证。

## 游戏内验收

- 生存模式打矮草或蕨能够获得三种药种；剪刀、创造模式不额外掉落药种。
- 三种作物能够种植、自然生长、骨粉催熟；成熟和未成熟的掉落不同。
- 普通合成与 Shift 连续合成研磨都消耗药杵耐久，最后一次工具损坏且仍产出药粉。
- 配制时返还空桶；营火与熔炉都能完成加工；配方书可解锁配方。
- 满饥饿值饮用、饮用堆叠中的最后一碗、背包满时饮用，容器返还和增益均正确。
- 重进世界后作物与物品保存正常，联机两侧安装后能够同步。

实际验证结果见 `VALIDATION.md`。
